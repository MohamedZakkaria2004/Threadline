# Reporting phishing and security concerns

Report suspected phishing emails to security@meridian.example within 15 minutes of discovery using the Report Phishing button in the mail application. Do not click suspicious links, open attachments, or reply to the sender. If a link was already clicked, disconnect the device from the network and contact the IT service desk immediately. Preserve the original email for the security team. This mailbox is a fictional demonstration address; the copilot does not send emails.
