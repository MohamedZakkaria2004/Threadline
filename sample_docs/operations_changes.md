# Planned network change procedure

Routine network changes use the Wednesday maintenance window from 22:00 to 02:00 local time. Submit a change request at least 2 business days before the maintenance window. Every request includes the affected services, implementation steps, a tested rollback plan, and validation checks. The change manager approves the request before execution. Emergency changes require explicit approval from the on-call operations manager and a retrospective review on the next business day.
